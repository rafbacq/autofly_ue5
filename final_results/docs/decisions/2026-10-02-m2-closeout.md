## Decisions

**M3's collection uses `best_model`** (`runs/expert/s01_r2/best/best_model.zip`, sha256
`8c2c7500041907a98d5d696b9007e30578731ff5136f63c384270c0f4fcbf8dc`, the file the gate scored).

`best_model` beat `final` in both gate conditions, 0.98/0.99 against 0.96/0.95, and `final` came in under the
threshold stochastically. Run 2's late training evaluations also dropped, ending at 0.65 at 450k steps. Training-time
evaluation is only 20 episodes per point, so that drop is weak evidence, but it agrees with the gate.

**Collection is stochastic, as spec §9 step 5 says.**

- The stochastic gate score (0.99) is at least the deterministic one (0.98), so stochastic collection costs nothing
  in kept episodes.
- AutoFly's experts are "stochastic policies" (spec §3.1), and stochastic actions give the dataset the action
  diversity a student needs. A deterministic expert repeats one trajectory per start.

The deterministic gate stays the acceptance bar for every later expert (M2d, M5). It is the stricter test of the
policy itself, and it keeps every gate comparable with M2's.

Settled by the user's plan of 2026-10-02 ("best_model flies M3 collection … collection is stochastic, per spec §9.5"),
which the user asked to have built out.
